GymMI is a chain of gyms operating in the Milan area with several locations. To expand its services, GymMI wants to allow its customers to autonomously book appointments with a nutritionist or with their personal trainer. To this end, GymMI relies on a new application solution that provides the necessary Web interface and integrates with both the existing ERP and CRM systems.
Regarding the ERP, integration takes place through shared access to the same database, while for the CRM, integration occurs at the application level through an API provided by the CRM and used by the new application. The application is a three-tier Web application based on an Oracle DBMS.
With reference to the text above, define the ArchiMate diagram composed of the Business Layer, Application Layer, and Technology Layer. Modeling of data objects and the technological layer of GymMI’s CRM and ERP is not required.
