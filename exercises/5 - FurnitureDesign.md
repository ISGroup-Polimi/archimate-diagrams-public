# Furniture design

A company decides to offer its customers a personalized furniture design service. The design process is handled by an operator who communicates with customers over the phone and creates a furniture project through a process that is initiated when the customer calls. The first phase involves collecting requirements, the second focuses on the personalized furniture design, and the third involves verifying the measurements. All these stages of the process define the design function.

As for the application side, the operator uses software called Autocad through its Graphical User Interface (GUI). Specifically, the Autocad GUI supports the second phase of the process defined above through the design service. Autocad supports the design functionality of the project, which, in turn, accesses the project itself.

Concerning the technology used to support the application, the company has installed Autocad in several desktop PC in the offices. All the projects created with this software are shared in a dedicated machine where the files are stored.

After some years, to support the remote working the company has decided to move the shared folder to a cloud service offering storage as a service.
