The company ACMEViaggi provides a personalized vacation planning service, which includes specific features such as booking flights, hotels, and museums for the selected destinations. The offered services can be accessed either by calling the company’s switchboard or by visiting the ACMEViaggi front desk. In both scenarios, an employee carries out the requested operations on behalf of the customer through a dedicated application that supports flight, hotel, and museum reservations. The employee is also able to process payments for the booked services using a second application.
Both applications (booking and payment) follow a two-tier architecture, using MySQL as the data layer and a Windows-based application handling both the application logic and the presentation layer.
