SummerFun is a company that manages summer activities for school-age children. The company organizes summer camps, guided visits to amusement parks, and vacation periods in tourist locations.
To access these services, SummerFun provides a call center service that allows customers to book one or more of these activities, as well as cancel or modify bookings. In particular, cancellations require approval from the SummerFun director.
To support booking management operations, SummerFun relies on an ERP system used by both the call center operator and the director. For auditing purposes, the application must periodically store all booking information on a Cloud storage system.
The ERP is a web-based client–server three-tier application. One node hosts only the database, running on an SQL Server platform; a second node runs an application server for executing the application logic; the third node simply hosts a browser.
